Custom Boot Splash (strict: must be exactly 128x64 pixels)
Converts a PNG to a 1-bit image and uploads it to the device - it replaces the built-in splash on the next boot. The source image must be exactly 128x64 pixels; anything else is rejected rather than resized, so the preview below is pixel-for-pixel what the device will show. Dark source pixels become lit ("on") pixels on the OLED by default - check Invert if your source image has it backwards (e.g. a light logo on a dark background).
RPM Log (requires DUMP_DEVICE's useRpmLogging set true)
Set useRpmLogging (and optionally rpmLogLength, capped at 2000) via the Config tab's DUMP_DEVICE/LOAD_DEVICE - no on-device menu item, Serial/web-console-only, same as DSHOT Mode and Verbose Serial. Capture starts automatically on the next trigger/rev pull after that reboot, dumps as CSV over Serial, then reboots again. Capture it straight from the Log console above, or open a saved file (a clean CSV or a noisy log dump - either is auto-extracted), then Chart it. Not tied to the live connection.
